# 从创新主张设计验证

用于需要具体实验安排、审查结果可信度或缩减实验预算的任务。按领域取舍，不要求所有实验都使用统计检验、消融或训练数据划分。

## 先明确可证伪的主张

句式：在【对象与条件】下，相对【参照】，改变【因素】通过【机制】使【主要指标】发生【有意义的变化】，同时满足【关键约束】。

把“提高性能”换成带单位和方向的指标。将预期机制与效果主张分开：效果改善不必然证明机制正确。若主要贡献是发现边界，主张可以是“条件 C 将导致方法失效”，而不要求发明新算法。

主张和检验之间建立对应：

| 主张类型 | 关键证据 | 最容易漏掉的反证 |
| --- | --- | --- |
| 效果更好 | 合理条件下与相关基线的比较及效果大小 | 预算增加、数据变更或不公平调参造成收益 |
| 成本更低 | 固定质量下成本降低，或完整的质量—成本取舍 | 把测量范围外的成本、预处理或维护开销排除 |
| 某模块或机制起作用 | 针对该模块的移除、替换或因素操纵 | 收益其实来自容量、额外信息或实现差异 |
| 更稳健 | 预先定义的扰动、强度与退化表现 | 只挑选改进方案擅长的扰动，或牺牲正常条件表现 |
| 发现规律或边界 | 覆盖相关条件的系统测量及复核 | 事后挑选子组、测量漂移或选择性汇报 |
| 新评价或测量方法有效 | 与可信参照、已知输入或独立判据的一致性 | 用该方法自己定义的真值验证自己，形成循环论证 |

## 对照与归因

基线应能回答用户关心的问题。复杂实验可包含简单但合理的基线和最接近方法；有限预算下先保留能区分关键解释的比较。

对齐数据或样品来源、处理方式、计算或器材配置、调参机会、负载和测量口径。无法对齐时标注差异，并相应限制归因。

两个因素 A、B 有实质相互作用的主张时，可用 B0、A、B、A+B 的设计。在指标尺度适合加法解释时，交互对比为：

`I = (y_AB - y_B) - (y_A - y_0)`

解释方向取决于指标，且需考虑不确定性；非线性尺度可能需要变换或其他模型。不要把“组合优于任意单项”直接当成存在协同作用的证明。

如果只改一个因素，简单配对或交错对照通常足够，不必为了形式扩大实验矩阵。

## 跨域联系的验证

把“这个方案有效”和“收益来自迁移的这项关系”分别检验。源学科中已有结论，只能作为形成假设的依据，不能充当目标实验的结果。

按候选的实际主张选择以下比较，不要求每项都运行：

| 比较 | 回答的问题 |
| --- | --- |
| 原方案与跨域方案 | 引入具体改动后是否改善任务结果，代价是什么？ |
| 最接近的目标领域方法与跨域方案 | 是否存在超出已有通用机制的差异？ |
| 保留与移除被迁移关系，其他关键信息和容量可比 | 结果是否依赖那条关系，而非更多资源或附加步骤？ |
| 必要前提成立与不成立的情境 | 映射是否预测了特定条件下的收益或失效？ |
| 真实关系与合理替代关系 | 该源关系是否比一般组织、随机安排或其他解释更有辨别力？ |

移除关系时不能同时删掉大量数据或计算，再把性能降低全部归因于关系本身。源实践提供的是表示方式或交互协议时，检验对应的任务效用；不要强行把它解释成与源学科相同的物理或社会因果机制。

若去掉学科名称后与已有方法完全一致，实验仍可能用于验证新场景或边界，但不能据此声称发明了新方法。远域灵感还依赖一个关键但未知的前提时，先设计验证该前提的低成本实验；没有预算则交付明确的研究路线，保留未解决状态。

## 实验单位与不确定性

- 指明什么是独立实验单位：不同受试者、独立样品、设备、运行批次或其他单位；同一样品的多次读数不自动增加独立样本量。
- 对有随机性的训练或运行使用合理重复；固定同一随机种子只方便复现，不等于估计了波动。重复次数根据先导方差、所需精度、相关性和预算决定，不统一套用“重复三次”。
- 需要时随机安排或配对实验条件、平衡运行顺序、记录预热和环境，以区分条件效应、时间趋势和个体差异。
- 报告与独立单位相符的汇总、效果大小和不确定性。单次结果只能作为观察；观测相关时不直接当作独立数据。
- 样本量或检验方法无依据时先做先导测量，再估计验证成本。统计不显著不等于两方案等效；置信区间过宽通常意味着证据仍不足。

## 领域中的关键控制

| 场景 | 需要特别检查的条件 |
| --- | --- |
| 机器学习 | 先划分再拟合预处理；验证集调参与模型选择，最终测试保持独立；时间序列按时间，相关样本按主体或群组划分；保留合理简单基线 |
| 软件与网络 | 固定硬件和负载分布，说明预热、缓存、并发、计时范围与尾部时延；负载生成器不应先成为瓶颈 |
| 嵌入式与控制 | 对齐板卡、时钟、编译选项、输入负载；说明外部参考、计时分辨率与仪器误差；区分仿真、台架和真实部署 |
| 物理与材料测量 | 校准与参照、样品独立性、批次效应、测量分辨率与环境；区分技术重复和独立样品重复 |
| 教学与行为研究 | 对齐或调整初始差异，明确分配单位、结果测量和流失；观察研究不直接作因果承诺 |

## 预算与事前判定

将验证拆成有退出条件的阶段：

1. **先导**：建立基线和测量方式，估计噪声与单次成本；排除无效信号、不可实现或明显超预算的方向。
2. **核心**：验证主要主张和最重要替代解释，固定主要指标与比较范围。
3. **扩展**：在核心结果值得继续时，增加条件覆盖、机制检查或独立复核。

先写出效果判据、关键质量约束和证据不足的条件。候选阈值注明依据是任务要求、测量精度、实际需求还是待校准假设。若预算仅足够先导，交付先导结果与下一阶段需求，不将其描述为完整验证。

搜索大量方案或多次查看结果后，不能把筛选中最好的那次当作未经选择的确认性证据。保留完整探索记录；必要时用独立数据或新实验复核。事后修改指标、排除规则和停止规则须披露，避免选择性汇报。

记录软件或装置版本、数据或样品标识、配置、环境、原始观测和失败运行。数据排除需要可解释规则；仅因结果不理想不能删除。
