# 远距离来源的搜索提示

按目标关系寻找来源，而不是随机拼接学科。下表是值得发问的方向，不是声称这些领域严格等价，也不证明某项迁移新颖或有效。源规则的实际含义、例外和文献需按任务核查。选几条相关路径即可，不必全部读取或使用。

| 目标中的具体关系 | 可探索的远域来源 | 值得问的迁移问题 | 主要失配风险 |
| --- | --- | --- | --- |
| 多个局部可行行为产生全局冲突 | 复调音乐、群体编舞、规则博弈 | 能否借用声部/角色约束、进入顺序或冲突解决方式，改变动作选择？ | 审美或排练中的规则不自动具有工程最优性；执行者的控制权不同 |
| 从不完整痕迹重建过程 | 考古地层、版本校勘、文物修复 | 能否把证据来源、层次和不可兼容解释显式编码，保留多个重建？ | 不能假定所有痕迹都按时间有序或独立；形式相似不等于来源可靠 |
| 有限资源下决定观察哪里 | 考古取样、生态样方、舞台注意组织 | 下一次观测应如何区分竞争解释，而非只追逐强信号？ | 观测是否会改变对象、信息是否可重复取得、观察者目标不同 |
| 保留重要历史，限制记忆成本 | 档案鉴定、口述史、策展组织 | 能否按证据独特性、重建价值和出处组织记忆，而非只按近期频率？ | 价值标准依赖任务；有意丢弃会造成不可恢复偏差 |
| 局部修补不应破坏整体 | 文物修复、文本校勘、工艺维修 | 能否把最小改动、可回溯记录或保留多版本变成算法/流程约束？ | 可逆性成本、真实性和工程性能不总是一致目标 |
| 同时维持结构与允许变体 | 韵律与诗体、语法演变、图案构成 | 能否分开不变关系和可变内容，用约束生成或评价替代整体模板匹配？ | 形式符合不等于语义正确、文化适当或任务有用 |
| 参与者目标不同而需要协调 | 组织程序、规则博弈、集体表演 | 能否改变信息揭示、行动次序或局部承诺，减少冲突？ | 人的意图、学习和权力不能默认等同于固定优化器 |
| 信息出现次序影响判断 | 叙事组织、展陈动线、教学讲解 | 能否将内容、证据或操作的呈现顺序作为干预变量？ | 主观体验与算法质量是不同结果；延迟揭示也可能降低效率 |
| 需要冗余又受成本限制 | 纺织结构、装配工艺、口头传承 | 能否在不同层次安排冗余、交叉核对或局部替换？ | 材料受力、记忆行为和数字误差的生成机制不同 |
| 部件之间连接关系决定可组合性 | 榫卯与构造、形式语法、乐句组织 | 能否以接口关系和局部兼容性限制组合，从而缩小无效搜索？ | 几何约束和抽象兼容性不能未经转换直接套用 |

## 扩展来源的操作

1. 先选目标中的一个关键关系；给它写两种不同的抽象描述。
2. 分别问“哪个领域长期处理类似关系”和“哪个领域处理相反条件”。第二问可找到前提边界，不必只找相似。
3. 选一个具体规则、操作或表示；“像生态”“像音乐”不是可迁移对象。
4. 写出规则在来源中的成立条件，再检查目标能否提供这些条件。
5. 若只是目标领域既有规则的新称呼，记录为重述并换源，或转向新的边界问题。

距离不是越大越好。源规则过于抽象、依赖无法观测的对象，或无法转成可比较操作时，换一条关系比增加更多领域名称更有价值。

## 两个构造示例与一个无效连接

以下仅示范推导，不是已运行结果，也没有核查其外部新颖性；这些来源不应成为所有任务的固定答案。

### 构造示例：档案组织启发有限容量记忆

- 目标：缓存大小固定，单按近期访问保留对象可能遗漏低频但独特的证据。
- 迁移对象：将“出处与可重建性”的组织视角转为可实现的保留条件，例如为已知证据类型维护覆盖；先确认这种视角在选用的档案资料中的实际定义。
- 对应：记录对应证据单元，来源组对应已知类别，丢弃后无法重建的内容对应高替代成本对象。
- 失配：计算系统的未来请求未知，档案价值也不能简化成访问收益；不能宣称“档案学证明这种缓存更优”。
- 最接近方法核查：目标领域可能已有多样性缓存、代表性选择或分组保留，必须比较具体规则。
- 区分性预测：若覆盖规则有价值，应在低频类别后续被请求的条件下改善覆盖；在请求集中于少量热门对象时可能牺牲命中率。比较常规基线与分组/多样性基线，并去掉覆盖条件。

### 构造示例：文本校勘启发多来源数据合并

- 目标：多个来源有局部冲突，直接覆盖或取多数可能丢失重要分歧。
- 迁移对象：把异文与来源关系显式保留，转成带出处的候选图和可追溯合并规则；具体源实践待资料核查。
- 对应：来源版本对应数据来源，局部异文对应冲突值，版本关系对应已知或待估计的来源依赖。
- 失配：来源依赖未知时不能把版本数量当独立票数；保留分歧也会增加下游成本。
- 最接近方法核查：需检查数据溯源、真值发现和版本合并等既有方法，不能以人文学科名称替代方法差异。
- 区分性预测：若显式依赖关系有用，它应在多个来源复制同一错误的场景中优于独立多数票；打乱来源关系或设为相互独立时不应保留相同优势。

### 无效连接：从陌生学科名直接推出测量精度

“给软件滤波加入量子纠缠概念，就能消除普通传感器未知的校准偏差”缺少可操作对象和有效连接。先检查目标是否有相应物理载体、可控状态和观测；没有这些条件，不能从该概念推出传感器准确度改善。

可以另行探索诗歌节律对采样安排的形式启发，但必须给出具体采样规则，与常规周期/随机策略比较。它仍不提供真实温度参照，不能据此证明绝对准确度。否定一个连接后可以换关系继续探索，无需否定整个学科交叉方向。
